# [План] Крупное обновление управления зданиями (Controls & Building Management Update)

Обновление системы управления зданиями: одноразовая/потоковая постройка (Shift), удаление по клавише Delete, рамка выделения через Ctrl+ЛКМ, групповое перетаскивание, а также копирование группы зданий через Ctrl+C с сохранением внутренних связей и последовательным расчетом стоимости.

## User Review Required

> [!IMPORTANT]
> **Ограничение зданий при копировании**: Здания, имеющие лимит на количество (например, `portal` с `max_count = 1`), автоматически отфильтровываются при копировании группы и не участвуют в предложении установки.

> [!NOTE]
> **Потоковая постройка с зажатым Shift**: 
> 1. Без `Shift`: после постройки одного здания режим постройки отменяется (`INSPECT`).
> 2. С зажатым `Shift`: при одиночных кликах или при зажатии ЛКМ и проведении мышкой по полю (Shift+ЛКМ drag) здания автоматически устанавливаются на каждую новую валидную позицию, если игроку хватает ресурсов.

> [!NOTE]
> **Отображение суммарной стоимости постройки группы**: При выделении нескольких зданий или в режиме копирования (Ctrl+C) выводится суммарная стоимость их постройки. Цвет суммы меняется динамически: зеленый/белый, если ресурсов хватает, и красный/оранжевый, если ресурсов недостаточно.

## Verification Plan

### Manual Verification
1. **Одноразовая установка и Shift (клики и непрерывное проведение)**:
   - Выбрать здание в магазине и кликнуть на поле без Shift -> здание ставится, курсор возвращается в режим `INSPECT`.
   - Зажать Shift и кликнуть несколько раз -> здания ставятся одно за другим.
   - Зажать Shift + ЛКМ и провести мышь по полю -> здания ставятся непрерывной цепочкой по сетке.
2. **Удаление через Delete**:
   - Кликнуть по зданию (выделить) -> нажать `Delete` -> здание сносится с возвратом ресурсов.
3. **Рамка выделения Ctrl + ЛКМ**:
   - Зажать `Ctrl` и потянуть ЛКМ -> рисуется рамка.
   - Выделяются только здания, которые целиком попали в рамку.
   - Кликнуть ЛКМ по пустому месту без Ctrl -> выделение снимается.
4. **Групповое удаление**:
   - Выделить рамкой несколько зданий -> нажать `Delete` -> все выделенные здания сносятся.
5. **Групповое перетаскивание**:
   - Выделить рамкой 3 здания -> зажать ЛКМ на одном из них и потянуть -> вся группа передвигается синхронно.
   - Навести на препятствие -> группа подсвечивается красным и не перетаскивается.
6. **Копирование Ctrl+C и инспектор**:
   - Выделить 2 связанных здания -> нажать `Ctrl+C`.
   - На панели инспектора/интерфейсе проверить отображение суммарной стоимости и цвета индикатора (зеленый / красный).
   - Проверить предпросмотр всей группы под курсором.
   - Кликнуть ЛКМ для установки -> создаются 2 новых здания, ресурсы списываются с учетом последовательного удорожания, связь между ними сохраняется.
   - Попробовать скопировать Портал (с лимитом) -> Портал исключается из копируемой группы.
   - Попробовать скопировать группу при нехватке ресурсов -> установка не предлагается.
