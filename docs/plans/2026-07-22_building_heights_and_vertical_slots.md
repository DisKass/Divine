# [План v2] QoL: Динамическая Высота Зданий, Ширина 4 и Вертикальное Разделение Входов/Выходов

## Описание обновленной концепции
Улучшение визуала и сетки зданий на основе новых требований:
1. **Ширина зданий**: уменьшается с 5 до **4 клеток сетки** (для стандартных фабрик). Маленькие здания (майнеры, сплиттеры) остаются 3 клетки по ширине.
2. **Вертикальное разделение ресурсо-портов**:
   - Входы и выходы больше не располагаются в одну горизонтальную строку.
   - Они идут последовательно друг за другом: **сначала входы (Inputs), ниже выходы (Outputs)**.
3. **Расположение и Высота**:
   - Шапка (название + прогресс-бар) = **1 клетка сетки по высоте**.
   - Ресурсы располагаются равномерно под шапкой: **не более 2 надписей на 1 клетку сетки по высоте**.
   - Дополнительный нижний отступ шапки/панели: **3px снизу**.
   - Формула высоты: `total_height_cells = 1 + ceil((inputs_count + outputs_count) / 2.0)` (минимум 2 клетки).

---

## Пример разметки размеров зданий `(ширина, высота)`

- `miner`: 3x2 (0 входов + 1 выход = 1 элемент => 1 клетка ресурсов + 1 шапка = 2 клетки высоты)
- `smelter`: 4x2 (1 вход + 1 выход = 2 элемента => 1 клетка ресурсов + 1 шапка = 2 клетки высоты)
- `converter`: 4x2 (1 вход + 1 выход = 2 элемента => 2 клетки)
- `assembler`: 4x3 (2 входа + 1 выход = 3 элемента => 2 клетки ресурсов + 1 шапка = 3 клетки)
- `infuser`: 4x3 (2 входа + 1 выход = 3 элемента => 3 клетки)
- `seller`: 4x2 (1 вход + 1 выход = 2 элемента => 2 клетки)
- `splitter_2`: 3x3 (1 вход + 2 выхода = 3 элемента => 3 клетки)
- `splitter_3`: 3x3 (1 вход + 3 выхода = 4 элемента => 3 клетки)
